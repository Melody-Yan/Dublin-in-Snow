# 都柏林的雪 · Dublin in Snow

一个只给自己用的中文私人手账：**书架、影单、心境手札**，装在一个页面里，离线也能写。

🔗 **在线地址：<https://dublin-in-snow.pages.dev>**
（手机浏览器打开后「添加到桌面」，就是一个全屏、无地址栏、断网也能开的 App）

数据全部存在**你自己的浏览器**里（localStorage），没有账号、没有服务器、没有上传。

---

## 有什么

| 栏目 | 说明 |
| --- | --- |
| **书架** | 都柏林的雪（想读）· 旅途中的灯（在读）· 落幕的章节（已读）· 遗忘的书页（弃读）；可记作者、评分、标签、书评 |
| **影单** | 想看 · 在看 · 已看 · 弃看；可记导演、评分、标签、短评 |
| **心境手札** | 碎碎念 · 随笔 · 灵感 · 长篇；支持 Markdown，写错了能改、能删 |
| **设置** | 音乐直链管理、导出 / 导入 JSON 备份 |

细节：

- 搜索**跨分类**找：在「书架」里搜，想读和在读的书都能搜到，卡片上会标出它属于哪一栏，免得「搜到了但不知道在哪一栏」；手札同理，跨四个格子找并标出命中的格子
- 背景随栏目切换（各有一张插图，加载不出来也不会白底白字）
- 音乐播放器全站只有一个：**切栏目不断**，进度条可点着跳，刷新页面接着播（位置记在 sessionStorage，关掉浏览器归零）
- 编辑是**原地修改**，不是新增一条；删除有二次确认
- 有 Service Worker：首次打开后会把页面缓存下来，之后断网也能开

## 怎么用

不用安装，浏览器打开 <https://dublin-in-snow.pages.dev> 就能写。
手机上想要个图标：浏览器菜单 →「添加到桌面」。

## ⚠️ 数据的两点实话

1. **数据只在这台设备的这个浏览器里**，按网址隔离。清浏览器数据、换浏览器、换设备，记录就看不到了。
2. **手机和电脑不互通**，各存各的。要搬家：老的 设置 → 导出笔记，新的 设置 → 导入备份。

> 所以：**导出备份这个按钮值得定期点一次。**

## 技术

纯静态，没有框架、没有构建步骤、没有后端：

```
index.html                  唯一页面（五个视图 + hash 路由）
app.js                      全部逻辑：数据 / 分页 / 评分 / 播放器 / 路由
style.css                   全站样式（唯一一份）
vendor/marked.min.js        自托管的 Markdown 解析（不依赖任何 CDN）
manifest.json               PWA 清单，可添加到主屏
sw.js                       Service Worker，离线缓存
icons/                      图标 192 / 512 / maskable / apple-touch
.well-known/assetlinks.json 安卓 App（TWA）去掉地址栏用的凭据
test_app.js                 冒烟测试
```

- 单页应用：`#books` `#movies` `#journal` `#settings` 切视图，切换时音乐不断
- 数据模型：`books` / `movies` / `entries` / `musicLinks` 四个 localStorage 键
- 所有用户输入渲染前都做转义；存储读坏时回退默认值而不是白屏

### 本地跑

直接双击 `index.html` 就能用；或者起个静态服务器：

```bash
python -m http.server 8080
```

### 跑测试

```bash
node test_app.js
```

70 条断言：纯函数（转义 / 评分 / 分页 / 标签）、五个视图与 `data-view` 是否一一对应、`app.js` 里每个选择器是否都能对上真实标记、`id` 是否唯一、manifest 与图标尺寸是否吻合、Service Worker 预缓存清单里的文件是否真的存在、assetlinks 包名与证书指纹格式。其中一条会用一个**永不返回 null 的假 DOM** 把 `init()` 完整跑一遍——空引用和拼错的 class 会在那里当场炸掉。

### 部署

托管在 Cloudflare Pages，属于纯静态直传：**Build command 留空，输出目录 `/`**。

## 已知限制：安卓 APK

试过用 PWABuilder 打成 TWA 的 APK（包名 `com.melody.dublininsnow`，签名与 `.well-known/assetlinks.json` 里的指纹对应）。结论：

- **有 Chrome 的手机**上可用，且与手机 Chrome 共享同一份数据
- **荣耀 / 华为等没有 Google 服务的机型打不开**——TWA 依赖 Chrome 的 Custom Tabs，这类机器上没有可用的 Custom Tabs 提供方，会一直停在启动图。这不是代码能补的

所以这台机器上的正解是「浏览器 + 添加到桌面」。
